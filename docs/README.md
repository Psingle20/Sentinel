# Documentation

This directory contains maintained engineering and product documentation.

- `architecture/`: system context, containers, components, data flows, and deployment views.
- `implementation/`: impact-ordered delivery phases, exit criteria, tests, risks, and architecture coverage.
- `decisions/`: architecture decision records for consequential choices.
- `business-contracts/`: business rules, capabilities, APIs, events, schemas, service agreements, and compatibility policies.
- `runbooks/`: deployment, rollback, incident response, recovery, and routine operations.

Prefer short indexes that link to focused documents. Date decisions and operationally sensitive material.

Start with the [phase-wise implementation plan](implementation/README.md) when planning delivery work, and the [phase status ledger](implementation/phase-status.md) to see how far each phase has got.
